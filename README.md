# Никита Нова — портфолио

Статический сайт без фреймворков. Русская версия в корне, английская в `/en/`.

## Как устроено

- `content.mjs` — все тексты на русском и английском: о себе, контакты, описания кейсов, порядок картинок.
- `cases/<папка>/` — картинки кейсов (`cover.avif` — обложка, остальные идут в галерею).
- `src/` — стили, скрипт анимаций, фото, иконка.
- `build.mjs` — собирает всё в папку `dist/`.

## Править и смотреть локально

```bash
npm run dev   # собрать и открыть http://localhost:4173
```

## Публикация

Любой пуш в `main` запускает GitHub Actions: сайт собирается и публикуется на GitHub Pages.

## Добавить новый кейс

1. Положить картинки в `cases/<папка>/`: `cover.avif` и `<префикс>1.avif`, `<префикс>2.avif`…
2. Добавить объект в массив `projects` в `content.mjs` по образцу соседних.
